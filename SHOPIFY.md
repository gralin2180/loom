# LOOM → Shopify (primary storefront)

Static `clothing/` is a **layout/reference shell only**.  
**Live selling happens on Shopify** so you can use Zendrop / AutoDS / DSers and real checkout.

---

## 1. Create the store (today)

1. Go to [shopify.com](https://www.shopify.com/) → **Start free trial** (3 days free; then paid plan).
2. Store name idea: **LOOM** (if taken: `wearloom`, `loomfits`, etc.).
3. Country / currency: pick where **you** operate (taxes & payouts follow this).
4. Skip “add products from template” junk — empty catalog is fine.

You’ll need:

| Item | Why |
|------|-----|
| Email you control | Shopify login + order mail |
| Bank / PayPal for payouts | Get paid |
| Domain later | Optional at first — use `yourstore.myshopify.com` |

---

## 2. Payments + shipping baseline

**Settings → Payments**

- Enable **Shopify Payments** if available in your country, else **PayPal** / manual options.
- Turn on **Shop Pay** when offered (higher Gen Z convert).

**Settings → Shipping and delivery**

| Approach | When |
|----------|------|
| General rates (e.g. flat $8 / free over $89) | Day 1 |
| **Easyship** or Shopify Markets duties later | When you go multi-country hard |

Don’t promise “3-day global shipping” until the **supplier** can hit that.

---

## 3. Fulfillment app (pick ONE primary)

Install from Shopify App Store after the store exists:

| App | Best for | Notes |
|-----|----------|--------|
| **[Zendrop](https://www.zendrop.com/)** | Branding + express options | Custom packaging tiers cost more |
| **[AutoDS](https://www.autods.com/)** | Automation / multi-supplier | Can get noisy; don’t auto-import junk catalogs |
| **DSers** | AliExpress only | Classic 1-unit China dropship |
| **Trendsi** (if they have Shopify app) | Fashion US-ish | Higher COGS, better feel |

**Do not also install CJ** for the same products.

**Rule:** import a product → **sample it** → then publish on the storefront. Never push 200 SKUs day one.

---

## 4. Theme (looks like a real clothes shop)

**Online Store → Themes → Explore free themes**

Start with a clean free theme:

- **Dawn** (official, fast, easy), or  
- **Sense** / **Craft** if you want softer lifestyle feel  

Then:

1. **Customize** → brand colors, logo “LOOM”, announcement bar (“Worldwide shipping · Free over $XX”)  
2. Homepage: **one hero** + featured collection — no ops/supplier copy  
3. Product template: description, size chart (use a size chart app or a page + metafield), size variant  
4. Pages: **Size guide**, **Shipping**, **Returns**, **Contact / Track order**

You can reuse LOOM *wording* from `clothing/` later; don’t paste CJ/ops text.

---

## 5. Catalog (no fakes)

For every product:

1. Pick it **inside** Zendrop/AutoDS/DSers from a real listing.  
2. Push to Shopify.  
3. Edit title/description to brand voice (honest fit, real fabric notes from supplier).  
4. Prices: sell price covers **product + shipping to customer + app fee + 30%+ cushion**.  
5. Variants = **size (+ color if real)**. Delete sizes the supplier doesn’t stock.

Optional CSV later (Settings / Products → Export) for bulk edits — only after a few live SKUs.

---

## 6. Markets / multi-currency (phase 2)

After 3–5 products sell without chaos:

- **Settings → Markets** → add countries you actually ship to  
- Local currency display  
- Duties with **Shopify Markets Pro** / **Easyship** when ready  

Don’t turn on 50 countries day one.

---

## 7. Tracking + customer trust

| Tool | Role |
|------|------|
| Supplier tracking → Shopify “Mark as fulfilled” | Baseline |
| **AfterShip** (Shopify app) | Auto status emails |
| Shopify **Inbox** or email | Size / “where is my order” |

Shipping policy page: **realistic windows** (e.g. 7–14 or 10–18 business days) matching your app/warehouse.
