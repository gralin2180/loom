# Suppliers — ops only

## Primary path: Shopify apps

| Goal | App / source |
|------|----------------|
| Branding + automation | **Zendrop** (Shopify app) |
| Heavy automation | **AutoDS** (don’t bulk-import trash) |
| AliExpress 1-unit | **DSers** |
| Fashion / faster US feel | **Trendsi** / Doba-style catalogs |
| Print tees | Printful / Printify (original art only) |

## Do not use for this project

- **CJ Dropshipping** (explicitly out)
- **Amazon retail** as inventory (research only)

## Rules

1. Products enter Shopify **from the fulfill app**, not from random Unsplash demos.  
2. Sample before hard marketing.  
3. Sell price ≥ product + ship + fees + healthy margin.  
4. One primary app first — don’t stack 4 competitors on day one.
